## 0. Expo context (read first)

- **Expo SDK 56+ deprecates `@expo/vector-icons`.** VERIFIED (opened) — official Expo SDK 56 changelog (https://expo.dev/changelog/sdk-56-beta, lines 399–403, 418–419): "`@expo/vector-icons` will be replaced by `@react-native-vector-icons/*`" (one scoped package per icon set, e.g. `@react-native-vector-icons/material-design-icons`); "the `expo` package no longer depends on `@expo/vector-icons`. If you wish to continue using `@expo/vector-icons`, you need to explicitly add it to your project's dependencies in `package.json`." **For SDK 58, use the scoped `@react-native-vector-icons/*` packages for new icon work.** `@expo/vector-icons` still works if added explicitly, and it is still the fastest zero-setup path in Expo Go.
- **Rendering SVG in Expo:** use `react-native-svg` (`expo install react-native-svg`). Raw `.svg` files are NOT renderable directly — convert to components (e.g. `react-native-svg-transformer` in a dev build, or inline the SVG path data into an `<Svg>` component). For web the same SVG files work natively.
- **PNG/JPG assets** work in Expo via `require()` / `expo-asset` with no extra setup — the fallback when an SVG can't be converted quickly.

## Conclusion (Figma-aware)

- **BEST PICK: unDraw** (https://undraw.co) — free SVG illustrations, commercial use, no attribution, one-click brand recolour, React Native package available. It is the fastest way to make the demo app look designed rather than empty. Grab 3–6 illustrations tonight (hero, empty state, success/celebration) in the app's brand colour, save as SVG files, render with `react-native-svg`. **Figma note: no official plugin — illustrations are edited by dragging the SVG into Figma (editable vectors), and brand colour is set on the website before download, so Figma recolouring is not needed.** If the team insists on a search-inside-Figma illustration workflow, there is no equally good free alternative — unDraw's SVG drag-in is the practical path.
- **BACKUP: fffuel** (https://www.fffuel.co) — free SVG background/decoration generators (blobs, waves, grainy gradients, 3D-feel shapes). Use for screen backgrounds and section dividers. Requires a human/browser to download the SVGs (no API). Figma: SVG drag-in only, no plugin.
- **Icons (companion, not the pick) — Figma-first choice: Hugeicons or Lucide.** Both have official Figma plugins and RN packages. **Hugeicons** has the strongest Figma-native workflow (native Figma components/variants, flip styles in the Properties panel, 4,600+ free icons) — pick it if the team designs in Figma first. **Lucide** is the safer default (ISC, outline-only, shadcn default, Figma geometry = code geometry 1:1). **Phosphor** is the third option (plugin + library, 6 weights). Pick exactly ONE icon set and stay consistent. Brand logos (incl. Claude/Claude Code) come from **Simple Icons** (`siClaude`), which also has a community Figma plugin. On SDK 58, prefer the scoped `@react-native-vector-icons/*` packages over the deprecated `@expo/vector-icons` wrapper.
- **Do NOT build the demo on free AI image APIs:** Pollinations anonymous tier paywalled after ~1 image in a Sep 2026 hands-on test, and Gemini image API has no quota on new free keys. If raster AI images are needed, generate a few manually in the Gemini app (free Google account, ~10–20/day) and bundle them as PNGs.

If dang meant a different specific repo (e.g. a `claude-code-icon` repo), that exact repo was not found — Simple Icons is the matching candidate.
